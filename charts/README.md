# Charts

Static output charts saved by the Python and R scripts. These are also rendered interactively inside the live dashboard.

| File | Script | What it shows |
|---|---|---|
| chart_lr_coefficients.png | 3_ml_models.py | Linear regression coefficients — which financial ratios drive net margin and by how much |
| chart_dt_importance.png | 3_ml_models.py | Decision tree feature importance — which variables the model relies on most to predict net income |
| chart_actual_vs_predicted.png | 3_ml_models.py | Side-by-side comparison of actual vs model-predicted values for both ML models |
| chart_arima_Total Revenue.png | 4_arima_forecast.R | ARIMA forecast for quarterly revenue through 2026 with confidence bands |
| chart_arima_Net Income.png | 4_arima_forecast.R | ARIMA forecast for quarterly net income through 2026 with confidence bands |
